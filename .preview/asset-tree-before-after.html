资产树视觉层级修复 · Before / After

DB 分组下 clickhouse 测试展开时,其内部 obj-node(default / zhht)与后面的 sibling 资产(测试环境 / ES日志服务器 / redis-正式环境 …)视觉上紧贴,缩进差仅 4px、字号差 1.5px、无引导线 — 让人误以为这些不同 dbType 的资产都是 clickhouse 的子节点。

根因: obj-node` 缩进只比 `tree-item` 深 4px,无视觉边界

`.obj-node` 的 `paddingLeft = 32px`(depth=1,`18 + 1×14`),`.tree-item` 的 `paddingLeft = 28px`;再加上 obj-node 没有包络、没有引导线、字号 11px vs 12.5px 差异过小,导致从 default → zhht → 过滤框 → sibling 资产,完全是同缩进同色调的连续行。
