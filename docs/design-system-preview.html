08 Before / After

改动前的痛点 vs 改动后的设计决策。

Before · Material Default
  • 裸 v-card / v-text-field / v-btn
  • 无设计语言,默认灰色阴影
  • v-card 套 v-card 双层容器
  • 状态点用 v-chip,占位大
  • Toolbar 死板,无操作分组
  • 认证方式用 v-btn-toggle,色块突兀
  • 没有 ⌘+Enter / Esc 快捷键
  • 没有任何 hover 动效
After · Cyber Command Center
  • 统一 .cyber-* 类,语义化命名
  • 深底 + 青/紫渐变高光 + glass blur
  • 扁平结构,form 不再套 card
  • 6px 状态点带脉冲 + 发光
  • mac 三点 + 实时连接时长
  • switcher 切换器,扁平 8px 圆角
  • ⌘+Enter 提交,Esc 取消
  • 200-300ms 动效曲线,统一节奏
