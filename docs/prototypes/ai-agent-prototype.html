HIERARCHY
5th type · 5 大类并列
Agent 走和 SSH 一样的 tree-group 视觉:chevron + type-icon(用 cyan→purple 渐变标识"AI") + label + count。子项 .tree-item = 一个 Agent,带 preset/custom 徽章 + status-dot(最近 30 分钟 used)。右键"新建 Agent"沿用 NewConnectionDialog 模式。
SAFETY
默认 ask before write
所有 destructive / write 类工具默认 ask,read 类自动通过,可在 Agent 编辑里改 policy。EXEC 后用户必须看到 DDL 预览。
CONTEXT
继承工作区
开 Agent tab 时自动带入 sidebar 已连接的 SSH / DB / Docker 作为可用工具;支持手动添加/移除 ctx-tag,像 Notion 标签。
ROADMAP
从 v0.19 起步
v0.19 sidebar tabs + Agent 索引 + 内置 4 个 preset;v0.20 自定义 Agent(编辑器 + 工具多选);v0.21 Runs / MCP 接入。
