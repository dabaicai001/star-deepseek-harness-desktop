# 本地工作区(Local Workspace)设计方案

> **状态**:草稿(v0.39.2 期间设计,未实施)
> **作者**:Mavis
> **关联 mockup**:`docs/previews/local-workspace-mockup.html`
> **拍板时间**:2026-08-04

---

## 1. 概述

把 StarHub 已有但**未被前端消费**的 `local.rs` 后端能力(`src-tauri/src/commands/local.rs:1-481` 的 8 个本地 FS/Shell command)落地为一个**一等 tab 工作区**,与 SSH / DB / Docker / Excel 平起平坐。

**与现有概念的关系**:

- **不是 SFTP 本地端**:SFTP 的本地栏是"为上传下载服务"的双栏对端;本地工作区是单边 + 编辑 + 终端,目标用户场景不同(开发调试本机项目)。
- **不是 AI 子模块**:AI 内的 `#LOCAL`(`src/services/aiLocal.ts`)目前是"开临时 shell 进程"的临时通道,本地工作区落地后,AI 复用 local tab 的状态而不是重新拉通道。
- **不是简单文件管理器**:对标 VSCode 的 "打开文件夹" 体验,但能力面更窄(不做 Git 集成 / 扩展 / 多根)。

## 2. 用户拍板的关键决策

| 维度 | 决定 | 备注 |
|---|---|---|
| 功能范围 | **4 象限全做**:目录树 + 文件列表 + Monaco 编辑器 + 本地 shell | 7-10 天工作量 |
| 资产管理 | **可以 + 可以**:支持把常用目录收藏成 local asset,也支持"快速打开"临时 tab | 两种入口并存 |
| AI 集成 | **全局生效**:AI 始终能读本机文件系统 | 见 §9 安全策略,默认走强提示 + allowlist |
| 多 tab 策略 | **支持多 tab**:可以同时开 N 个本地工作区 tab(类比 SFTP) | 与现有 tab 体系一致 |

## 3. 功能边界

### 3.1 MVP(v0.40 目标)

- ✅ 一等 tab 类型 `TabType: 'local'`
- ✅ 一等资产类型 `AssetType: 'local'`(可选,可临时开)
- ✅ 4 象限:目录树 / 文件列表 / Monaco 编辑器 / 本地 shell
- ✅ Monaco 多 tab:编辑 / 预览 / diff
- ✅ 文件 CRUD(read / write / mkdir / copy / move / remove)走 `local.rs` 已有 command
- ✅ 拖拽上传 / 从 SFTP 拖过来粘贴(沿用 `transferStore`)
- ✅ 标签栏 detach 到独立窗口(沿用 `windowDetach` 已有机制)
- ✅ AI 全局生效 + 强安全提示 + allowlist 默认值
- ✅ 暗色 / 浅色双主题(走 `cyber.css` token,不改组件内样式)
- ✅ i18n(zh-CN / en-US)

### 3.2 不在 v0.40 范围(后续 PR)

- ❌ Git 集成(git2-rs 依赖,体积大)
- ❌ 多根工作区(VSCode 那种,复杂度高)
- ❌ 全局搜索(先支持单目录文件级搜索,grep 下个版本)
- ❌ 文件 watcher / 自动重载
- ❌ 扩展 / 插件(架构上预留,不做)
- ❌ 远程本地工作区(以后走 SSH 通道)

## 4. 信息架构

```
┌── 顶栏 ───────────────────────────────────────────────────────────┐
│ [Tab 栏: ... | local:starhub ×]                                  │
│ [工具栏: 打开目录 ▾] [刷新] [搜索 ⌘P] [视图切换] [AI 入口 🔒]      │
├──────┬───────────────────────────────────────────────────────────┤
│ 目录 │ 主区域                                                     │
│ 树   │ ┌─────────────────┬─────────────────────────────────────┐ │
│  ~   │ │ 文件列表 (grid) │ 编辑器 / 预览 / diff (Monaco 多 tab) │ │
│ ~ ~  │ │  + 多选 + 右键   │ - README.md (markdown 预览)         │ │
│ ~    │ │  - src/         │ - Cargo.toml (编辑)                  │ │
│      │ │  - docs/        │ - diff (与 HEAD 对比)                │ │
│      │ │  - package.json │                                     │ │
│      │ └─────────────────┴─────────────────────────────────────┘ │
│      │ 终端 (xterm, cwd = 当前选中目录)                            │
├──────┴───────────────────────────────────────────────────────────┤
│ 状态栏: /Users/.../starhub | 187 items | ⌘P 搜索 | local: enabled  │
└──────────────────────────────────────────────────────────────────┘
```

### 4.1 4 个象限的职责

| 象限 | 组件 | 职责 | 关键交互 |
|---|---|---|---|
| 左 | `DirTree.vue` | 目录树,懒加载 | 单击选中,双击进入文件,右键 CRUD |
| 中上 | `FileGrid.vue` | 当前目录文件列表 | 多选 / 排序(名称/大小/时间) / 右键 |
| 中右 | `EditorPane.vue` | Monaco 多 tab | 标签栏编辑 / 预览 / diff 切换,⌘S 保存 |
| 下 | `LocalTerminal.vue` | 本地 shell(xterm) | cwd 跟选中目录同步,⌘L 清屏 |

### 4.2 跨象限状态

- **当前目录**:目录树选中、文件列表显示、Monaco 打开文件、shell cwd —— 全部由 `localViewStore.currentPath` 单一来源驱动。
- **选中文件**:文件列表多选会同步给状态栏;右键菜单根据多选 / 单选切换动作集。
- **脏文件**:Monaco 改未存 → 标签名后 `●`;关闭 / 切 tab 时弹确认。

## 6. 数据模型

### 6.1 `Asset` 扩展(`src/types/asset.ts`)

```typescript
export type AssetType = 'ssh' | 'db' | 'docker' | 'excel' | 'local'

export interface AssetConfig {
  // ... 现有字段不动

  // 本地工作区
  rootPath?: string              // 工作区根目录绝对路径
  lastCwd?: string               // 上次 cwd(下次打开恢复)
  view?: 'tree' | 'grid'         // 默认视图
  aiAllowRead?: boolean          // 是否允许 AI 读此工作区(默认 true)
}
```

### 6.2 `Tab` 扩展(`src/stores/app.ts`)

```typescript
export type TabType = AssetType | 'ai' | 'web'
// 即: 'local' | 'ai' | 'web' | 'ssh' | 'db' | 'docker' | 'excel'

interface LocalTabData {
  rootPath: string

  terminalVisible: boolean

interface LocalOpenFile {
  path: string
  kind: 'edit' | 'preview' | 'diff'
  dirty: boolean
}
```

## 7. 状态机

### 7.1 Local tab 生命周期

```
[idle] --点击"打开本地工作区"--> [selecting] --选根目录--> [opening]
[opening] --成功--> [active] --关闭 tab--> [closing] --保存/丢弃--> [idle]
                                              \
                                               --保存到 history--> [recent]
```

### 7.2 Monaco tab 状态

```
[closed] --双击文件--> [loading] --成功--> [clean] --修改--> [dirty]
[clean] / [dirty] --⌘S--> [saving] --成功--> [clean]
                                      --失败--> [dirty, error]
[dirty] --关闭--> [confirm] --保存--> [saving]
                       --丢弃--> [closed]
                       --取消--> [dirty]
```

## 8. 消费 `local.rs` 的 command 清单

| 后端 command | 前端消费方 | 用途 |
|---|---|---|
| `local_system_info` | `LocalView.vue` onMounted | 获取 home / shell / 平台信息,初始化欢迎页 |
| `local_list_directory` | `DirTree` / `FileGrid` | 列目录(单次最多 500) |
| `local_stat_path` | `FileGrid` / 状态栏 | 取文件大小、修改时间 |
| `local_read_text_file` | `EditorPane` | 读文本文件(分段,>1MB 截断) |
| `local_write_text_file` | `EditorPane` | 写文件(覆盖/追加,可选创建父目录) |
| `local_create_directory` | `DirTree` / `FileGrid` 右键 | 新建目录 |
| `local_copy_file` | 同上 | 复制 |
| `local_move_path` | 同上 | 移动 / 重命名 |
| `local_remove_path` | 同上 | 删除(可选递归) |
| `local_shell_exec` | `LocalTerminal` | shell 命令(非交互,30s 默认超时) |
| `open_file_external`(`file.rs:5`) | `FileGrid` 右键 | "在系统应用中打开" |

**注意**:`local_shell_exec` 是**非交互**的,不能直接喂 xterm。xterm 需要 PTY。`LocalTerminal` 两种用法:
- **简单模式**(MVP):用 `local_shell_exec` 跑单条命令,输出贴到 xterm 区域。够用,但不能交互。
- **PTY 模式**(v0.41+):Tauri 侧加 `portable-pty` crate,给 xterm 喂真 PTY。能 `vim` / `htop`。

**MVP 选简单模式**。等用户喊"我要跑 vim"再加 PTY。

## 9. AI 全局生效的安全策略

> 用户决策:AI **始终能读**本机文件系统。
> 这是高权限,需要 3 层兜底。

### 9.1 提示层(必做)

- AI tab 顶部常驻一条**红色警告条**:
  > 🔒 AI 当前可读本机全盘。敏感目录(`.ssh/`, `.aws/`, `.env*`, `id_rsa*`)默认被 allowlist 排除。
- 每次 AI 想读 / 写文件,弹**确认卡**(沿用 `src/components/ai/ConfirmCard.vue` 已有机制)。
- Settings → AI 加一个总开关:「允许 AI 访问本机文件」,默认 **ON**;关闭后所有 local 命令被前端拦截,返回 `permission denied`。

### 9.2 Allowlist 层(必做)

`src/services/aiLocal.ts` 维护硬编码 allowlist **deny** 规则(高危目录绝对不读):

```typescript
const DENY_PATH_PATTERNS = [
  /\.ssh\//,
  /\.aws\//,
  /\.gnupg\//,
  /\.kube\//,
  /\.docker\/config\.json/,
  /\.netrc$/,
  /\/id_rsa($|\.)/,
  /\/id_ed25519($|\.)/,
  /\.env($|\.)/,
  /\.npmrc$/,
  /\.pypirc$/,
  /password|secret|credential|token/i,  // 文件名包含这些的额外提示
]
```

- 在 `src/services/aiLocal.ts` 加 `isPathDenied(path: string)` 检查;命中直接抛错。
- 这层**前端写死**,后端 `local.rs` 也加同样检查(`src-tauri/src/commands/local.rs` 加 deny check,双保险)。

### 9.3 后端权限层(必做)

Tauri capability(`src-tauri/capabilities/main.json`)的 `local_*` commands 加 `allow` 策略:

```json
{
  "identifier": "local:allow-read",
  "allow": [{ "path": "**" }]   // MVP:全开
}
```

未来加细粒度控制(按 asset 限制路径),但不在 v0.40 范围。

### 9.4 用户教育层(必做)

- 首次打开本地工作区 tab 弹一次 onboarding 提示。
- AGENTS.md / 用户文档明确写"AI 读本机的范围 + 如何关闭"。

## 12. 风险与兜底

| 风险 | 概率 | 兜底 |
|---|---|---|
| `local_shell_exec` 非交互导致 xterm 不能跑 `vim` | 高(MVP 已知) | 简单模式 + 文案明示;v0.41 上 PTY |
| 大目录(node_modules / .git)卡死 | 中 | 目录树懒加载;FileGrid 单目录最多 500 项;`.gitignore` 标记的目录可右键"隐藏" |
| 用户把工作区根设到 `C:\` 整盘扫描 | 中 | `local_list_directory` 单次最多 500 项硬限;UI 提示"建议选具体项目根" |
| AI 全局生效被滥用读隐私 | 低(已加 deny) | §9 三层兜底;Settings 总开关可关闭 |
| Monaco 大文件卡死 | 中 | `local_read_text_file` 单次 1MB 截断;>1MB 弹"用外部应用打开" |
| Tauri 权限泄漏 | 极低 | capability 显式 allow;未来加路径范围限制 |
