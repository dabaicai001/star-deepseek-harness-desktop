## §8 已由主会话完成的修复(不要重复,改动时勿回退)

1. **自定义模型沙箱报错**:`sandbox escalation to "workspace-write" is not strictly
   wider than this call's current "danger-full-access" mode` —— 根因:会话文件策略已是
   最宽 `danger-full-access`(base bundle `sandbox-policy.mode` 默认 workspace-write,
   但用户设置或会话切到了 full-access),弱模型在 bash 调用里带 `sandbox_permissions`
   升级字段,而"升级到更窄模式"被 `approveEscalation` 拒绝。修复:
   `packages/sandbox/sandbox/src/escalation.ts` 新增 `modeCovers()`:请求模式已被当前
   模式覆盖(相等或更窄)时按 no-op 放行(返回 effectiveMode),仅未知模式仍 fail-closed。
2. **自定义模型不支持图片**:根因 pi-ai 模型 profile 默认 `input: ['text']`,且模型编辑
   UI 没有图片开关。修复:`packages/client/ui-settings-models` 的
   `DeepSeekModelsEditor.tsx` / `ModelListEditor.tsx` 高级区新增「支持图片输入」复选框
   (写 `input: ['text','image']` / 删除),locales 加 `imageInput`/`imageInputHint`
   (en+zh),CSS 加 `.modelCheckbox`。**3086 已验证勾选框出现**。
3. **subagent 默认走 deepseek 而非指定模型**:根因 `resolveChildAgentOptions` 继承父
   agent 的**创建时 options**(默认模型),而用户在 UI 切换模型只更新了会话 request
   header,不更新 `agent.options`。修复:
   `packages/subagent/subagent/src/child-agent.ts` 与 `continuation.ts` 优先读
   `parent.session.requestHeader()?.config` 的 provider/model/maxTokens,回退
   `parent.options`;新增单测(模型切换继承)。

**bundle 已重建并部署到 3086**(sandbox/subagent/ui-settings-models 的 lib 已更新)。
