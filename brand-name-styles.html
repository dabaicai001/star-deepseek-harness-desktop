"StarHub" 怎么写才够赛博

现状是大写 Outfit 800 + 渐变 shine, 跟其他 dashboard 标题太像。挑一个更有"产品品牌"感的写法。 每个都保留 v0.38.3 56-64px 级别主标题位, 不影响其他元素。

Star 青色 + Hub 紫色
StarHub
双色对照: Star 青色 + Hub 紫色, 一眼分两半
双色发光, 品牌识别度最高
改动: 模板里把 StarHub 拆成两个 <span>

我的建议

推 A 双色拼接: 最直接, 品牌识别度最高, 改动最小。 如果你想要更"产品定位"感(带 v0.38.3 + 副标)就选 F; 想要 hacker 复古感选 E; 想要国际化大写选 C。

选定后, 模板里把 StarHub 改成 <span class="brand-a">Star</span><span class="brand-b">Hub</span> 这种结构即可, CSS 加 .brand-a / .brand-b 两个 class。
